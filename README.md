# NanoTicket

Small, safe, verifiable task contracts for AI coding agents.

Install:

```bash
npm install -g @gfunkytheanimal/nanoticket

USE:

nanoticket init
nanoticket new "Fix one bug safely"
nanoticket validate nanotickets/001-fix-one-bug-safely.md
nanoticket audit nanotickets/001-fix-one-bug-safely.md
